# Security Policy

## Supported Versions

This is a research/reference project originally published in 2017 and modernized for Python 3.
Security updates are provided on a best-effort basis for the latest `master` branch only.

## Reporting a Vulnerability

Please do **not** open public issues for suspected vulnerabilities.
Instead, report vulnerabilities privately through GitHub:

1. Go to the repository **Security** tab.
2. Click **Report a vulnerability**.
3. Provide reproduction details and impact.

This allows coordinated disclosure before fixes are published.

## Response Timeline

Reports are reviewed on a best-effort basis for this personal/research project.
Initial acknowledgement is typically provided within 7 days, with follow-up timing depending on severity and maintainer availability.
